## 🚀 Setup

No installation needed:

```bash
git clone https://github.com/regis-chifambaa/portfolio.git
cd portfolio
open index.html
```

To deploy on GitHub Pages:
1. Push to GitHub
2. Settings → Pages → Source: `main` branch
3. Your site will be live at `https://regis-chifambaa.github.io/portfolio`

---

## 📝 Customise
update these in `index.html`:
- Project `Live Demo →` and `GitHub` links → your actual project URLs
